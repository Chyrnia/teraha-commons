# teraha-commons

`commons` es una librería creada para el proyecto de la materia **Sistemas Distribuidos** de la FIUNI.

Su función actualmente es proveer las entidades de dominio del sistema distribuido en construcción.

## Tecnologías

### JPA/Hibernate

Para realizar el mapeo de entidades entre Java y la base de datos, utilizamos las anotaciones de **Jakarta Persistence API (JPA)**, con **Hibernate** como proveedor de la implementación.

### Liquibase

Las migraciones de la base de datos son versionadas utilizando **Liquibase Community Edition**.

### Lombok

La librería **Lombok** provee anotaciones que generan código *boilerplate*, de modo que nuestras clases sean más sucintas y claras.
